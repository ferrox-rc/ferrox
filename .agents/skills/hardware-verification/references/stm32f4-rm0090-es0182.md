# STM32F407 Reference & Errata (RM0090 / ES0182)

## Clocks & Bus Domains
- **SYSCLK**: `168 MHz` (`12 MHz` HSE on Pocket/QX7 family -> PLL), `HCLK = 168 MHz`.
  - `1 ms` = `168_000` cycles (`cortex_m::asm::delay(168_000)`).
  - `APB1 (PPRE1 = /4)`: `42 MHz` (timers `84 MHz`).
  - `APB2 (PPRE2 = /2)`: `84 MHz` (timers `168 MHz`).
  - Guard `HSERDY`, `PLLRDY`, and `HSIRDY` waits with bounded timeouts before switching `SW`.
- **RCC Clock-Enable Delay (ES0182 §2.1.13 / RM0090 §7.3)**: After enabling a GPIO or peripheral clock in `RCC_AHB1ENR` / `APB1ENR` / `APB2ENR`, perform a dummy read-back (`let _ = rcc.ahb1enr.read().bits();`) before writing peripheral registers.

## I2C1 (RM0090 §27.3.3 & ES0182 §2.14)
- **Fast Mode 400 kHz @ 42 MHz APB1**: `CCR = 42 MHz / (3 * 400 kHz) = 35` (`0x8000 | 35`), `TRISE = (300 ns * 42 MHz) + 1 = 14`.
- **1-Byte Master Receive (EV6_1)**: Clear `CR1.ACK` and set `CR1.STOP` *atomically* right after clearing `ADDR` (inside `cortex_m::interrupt::free`) before waiting for `RXNE`.
- **Error Recovery**: On any timeout or NACK (`SR1.AF`), send `STOP` and restore `CR1.ACK` so the bus is not left wedged.
- Guard `buf.is_empty()` and `addr.checked_add(len)` before transfers.

## SPI (RM0090 §28)
- Read `SPI_DR` after `RXNE` on every byte (including TX-only bursts) to prevent `OVR` (Overrun).
- Wait for `SR.BSY == 0` with a bounded timeout before deasserting `CS` or changing LCD `DC`.
- Use `OSPEEDR = High Speed` (`0b11`) on high-speed SPI pins (`SPI2` SD card, `SPI3` LCD).

## DMA2 (RM0090 §10.3.17)
- Before reconfiguring a stream: clear `SxCR.EN = 0`, poll `EN == 0` with a bounded timeout, then clear stream flags in `LIFCR` / `HIFCR`.
- Read `RX_DMA_BUF` via `core::ptr::read_volatile`.

## USART1 Half-Duplex (RM0090 §30.3.10)
- `CR3.HDSEL = 1` enables single-wire half-duplex mode on TX (`PB6`).
- Guard `TXE`/`TC` waits with bounded timeouts and return early on failure.

## DFU Bootloader Entry (RM0090 §2.4)
- `DFU_BOOTLOADER_ADDR = 0x1FFF_0000`.
- Reset RCC to HSI (`16 MHz` with `HSIRDY` timeout), disable SysTick, clear `SCB.ICSR.PENDSTCLR` (`1 << 25`), clear NVIC `ICER`/`ICPR`, set `SYSCFG_MEMRMP.MEM_MODE = 0b01`, execute `DSB`/`ISB`, and bootstrap MSP + Reset handler.
- `.uninit` retained flags (`DFU_RETAINED_FLAG`, `PANIC_COUNT`) must use `MaybeUninit<u32>` with volatile `u32` pointer casts.
