# STM32F072 / APM32F072 Reference & Errata (RM0091 / ES0260)

## Clocks & Memory Map
- **SYSCLK**: `48 MHz` (`8 MHz` HSE * 6 PLL), `HCLK = 48 MHz`, `PCLK (APB) = 48 MHz`.
  - `1 ms` = `48_000` cycles (`cortex_m::asm::delay(48_000)`).
  - `FLASH_ACR.LATENCY = 1` required above `24 MHz` (RM0091 §3.5.1).
  - Guard `HSERDY`, `PLLRDY`, and `HSIRDY` waits with bounded timeouts before switching `SW`.
- **STM32F072 vs APM32F072**:
  - `UID_BASE`: `0x1FFF_F7AC` (STM32) / `0x1FFF_F7E8` (APM32).
  - `DFU_BOOTLOADER_ADDR`: `0x1FFF_C800` (STM32F072) / `0x1FFF_F000` (APM32F072).

## Cortex-M0 (`thumbv6m-none-eabi`) Atomics
- Cortex-M0 has **no** `LDREX`/`STREX` hardware CAS (`AtomicBool::swap` / `compare_exchange` do not exist).
- Use `cortex_m::interrupt::free` with `Atomic*::{load, store}` for read-modify-write synchronization.

## DFU Bootloader Entry
- Reset RCC to HSI (`8 MHz`), disable SysTick counter & interrupt, and clear pending SysTick via `SCB.ICSR.write(1 << 25)` (`PENDSTCLR`).
- Disable/clear all NVIC interrupts, remap System Memory (`SYSCFG_CFGR1.MEM_MODE = 0b01`), execute `DSB`/`ISB`, and bootstrap MSP + Reset handler from `DFU_BOOTLOADER_ADDR`.
- `.uninit` retained flags (`DFU_RETAINED_FLAG`, `PANIC_COUNT`) must use `MaybeUninit<u32>` with volatile `u32` pointer casts.

## Peripheral Notes & Errata
- **RCC Clock-Enable Delay (ES0260)**: Perform a dummy read-back of `RCC_AHBENR`/`APBENR` before accessing a newly enabled peripheral.
- **USART_ICR (RM0091 §27.8.9)**: Valid write-1-to-clear bits are `0x0012_1B5F` (`PECF`, `FECF`, `NCF`, `ORECF`, `IDLECF`, `TCCF`, `LBDCF`, `CTSCF`, `RTOCF`, `EOBCF`, `CMF`, `WUCF`). Do not write `0xFFFF_FFFF` to reserved bits.
- **USART DMA & Half-Duplex (RM0091 §9.1.1, §27.5.10, §27.5.13)**:
  - `SYSCFG_CFGR1.USART2_DMA_RMP` is **bit 25** (`w.usart2_dma_rmp().remapped()`, `1 << 25`) to remap `USART2_RX`/`TX` from DMA1 Ch5/Ch4 to Ch6/Ch7 (bit 9/10 are `USART1_TX`/`RX_DMA_RMP`).
  - Clear `USART_ICR.TCCF` (`1 << 6`) before enabling the TX DMA channel (`DMA_CCR_EN`) so a stale `TC` flag cannot fire `TCIE` prematurely.
  - In single-wire half-duplex mode (`HDSEL = 1`), configure TX pin (`PD5` on i6x, `PB6` on i6s) as Open-Drain with internal Pull-Up (`OTYPER = 1`, `PUPDR = 0b01`) and float the unused RX pin as input.
  - Read `RX_DMA_BUF[tail]` via `core::ptr::read_volatile`.
- **TIM15_SR / Timer Status Registers (RM0091)**: Status flags are `rc_w0` (write `0` to clear, `1` has no effect). Clear a flag with `sr.write(|w| w.bits(!(1 << bit)))` — never read-modify-write (`r.bits() & !mask`), which races with hardware setting another flag.
- **I2C1 Recovery (RM0091 §26.4.3)**: On bus error or timeout, toggle `CR1.PE = 0` (held >= 3 APB clock cycles), clear `ICR`, then set `PE = 1` to reset internal state machines.
- **USB Device (RM0091 §30.6)**:
  - `USB_EPnR` mixes `t` (toggle: `DTOG_RX`, `DTOG_TX`, `STAT_RX`, `STAT_TX`) and `rc_w0` (`CTR_RX`, `CTR_TX`) bits. Write `0` to `t` bits and `1` to `rc_w0` bits to preserve them.
  - Clamp `ep0_start_in` length to `CONTROL_DATA.len()`.
  - Wrap `SERIAL_HANDLER` access in `poll()` inside `cortex_m::interrupt::free`.
